## Common Issues & Practical Fixes


### Icon Not Appearing
**What to try:** Ensure that the application has the necessary permissions in *System Settings > Privacy & Security > Accessibility*.


### Layout Resetting
**What to try:** Check for macOS system updates, as OS-level changes to the menu bar can occasionally reset icon positions.


### High CPU Usage
**What to try:** Ensure you are running the latest version of the software, as performance optimizations are included in regular updates.
